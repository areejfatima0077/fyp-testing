# MeritSphere — final (Theme B design + all original screen content)

Plain HTML/CSS/JS, no build step.
Run: open the folder in VS Code → right-click `index.html` → Open with Live Server. Fonts (DM Sans, DM Serif Display) are bundled in `fonts/`, so it works offline except for the optional hero photo.

Screens (hash routes): #/navigator · #/results · #/calculator · #/explore
- `css/base.css` — Theme B tokens and components (unchanged from the approved Theme B).
- `css/styles.css` — layout for the four screens.
- `js/data.js` — program records and formulas taken from your original file.
- `js/app.js` — screens, live calculations, filters, comparison dock, routing.

Everything the original screens contained is here. Values are illustrative sample data from the original design; verify against official notices before relying on them.
